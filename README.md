# Daily Work Manager (Android APK Auto-Build)

1. Upload all files inside this folder to a new GitHub repository.
2. Open the **Actions** tab in your GitHub repository.
3. Wait ~2–3 minutes for **Build Daily Work Manager APK** to finish with a green checkmark.
4. Click the completed run → scroll down to **Artifacts** → download **DailyWorkManager-APK**.
5. Unzip and install `DailyWorkManager.apk` on your Android phone.
